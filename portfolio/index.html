Mathematical research leaderboard

Ordered here for portfolio readability, not numerical merit. Each entry links an established result or mathematical identity to a particular use in the DoinBetter design vocabulary. The published mathematics does not independently verify the entire proposed software architecture.

REFERENCE 01 · Established result

Fano plane / PG(2,2)

Credit: Gino Fano; standard finite-geometry literature

What is established: Seven points, seven lines, three points per line; automorphism group order 168.

System alias: Seven-gate incidence and routing vocabulary; do not equate the whole network with a proven Fano construction.

Credit: Number theory and Catalan combinatorics

What is established: 42 is sphenic; the fifth Catalan number equals 42.

System alias: 42-slot coordinate design and expression-tree enumeration. The equivalence of arbitrary runtime plans to Catalan trees is a design mapping, not automatic.

REFERENCE 03 · Defined operator

Fractional-order memory / Caputo

Credit: Michele Caputo; numerical work by Yoon and You

What is established: A Caputo derivative is a history-weighted integral of a derivative, with a specified fractional order.

System alias: Long-memory workflows and memory-kernel comparisons; 0.743 is a user-selected parameter, not a theorem.

Octonions and exceptional G₂

Credit: Élie Cartan; expositions by John C. Baez

What is established: Compact G₂ is the 14-dimensional automorphism group of the octonions.

System alias: Seven-imaginary-basis and geometric-constraint research; does not itself validate the full system topology.

Credit: A. J. Stone and D. J. Wales (1986)

System alias: Fullerene-inspired face and neighborhood transformations. Software topology and physical molecular mechanics remain distinct.

05 · Source shelf

Original repository titles, retained as source coordinates

Public repository names are preserved exactly. Their README may describe an upstream program rather than the function being explored under the repository's new title. The source license and original authorship continue to apply.

Read the attribution rule

Authorship is assigned at the code or research contribution, not inferred from who holds a GitHub mirror. A merged repository can preserve a complete upstream application while adding a different contextual function. Mathematical citations are proof of the cited mathematical facts, not proof that every numerical parameter or performance claim in the surrounding narrative is correct.
