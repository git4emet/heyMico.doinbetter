## 5. Status Vocabulary

Use exactly these labels. No synonyms.

| Label | Meaning |
|-------|---------|
| `live` | Publicly reachable, verified, part of the system. |
| `staged` | Built and verified locally, not yet promoted. |
| `prototype` | Works, but not integrated. Sample data or simulated controls. |
| `planned` | Designed, not built. No public artifact. |
| `deprecated` | Was live, now replaced. Kept for receipts. |

Honest labels only. If a control is simulated, say `prototype`. If a backend is sample data, say `prototype`.

## 6. Identifiers

Every artifact gets a stable ID.

Format: `MOB-{ORGAN}-{TYPE}-{YYYYMMDD}-{NNN}`

- `ORGAN`: `ONE`, `SB`, `SR`, `MALL`, `MOD`
- `TYPE`: `SRC` (SourceCard), `SHF` (ShiftEvent), `LED` (Ledger), `RCP` (Receipt), `DOC`, `CODE`, `HW`
- Example: `MOB-SR-SRC-20260910-001`

IDs are never reused. If an artifact is superseded, the new one gets a new ID and references the old one.
